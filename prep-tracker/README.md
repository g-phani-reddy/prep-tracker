# Backend Prep Tracker — PWA

A 6-month backend engineer interview prep tracker. Mobile-first PWA, installable on your home screen.

## Deploy in 3 steps

### 1. Create a GitHub repo
- Go to github.com → New repository → name it `prep-tracker` → Public → Create

### 2. Upload these files
Upload all files in this folder:
- `index.html`
- `manifest.json`
- `sw.js`
- `icon-192.png`
- `icon-512.png`

### 3. Enable GitHub Pages
- Repo → Settings → Pages → Source: Deploy from branch → Branch: main → / (root) → Save
- Your app is live at: `https://YOUR_USERNAME.github.io/prep-tracker`

## Install on your phone

**Android (Chrome):**
1. Open the URL in Chrome
2. Tap the 3-dot menu → "Add to Home screen"
3. Tap "Add"

**iPhone (Safari):**
1. Open the URL in Safari
2. Tap the Share button (bottom)
3. Scroll down → "Add to Home Screen"
4. Tap "Add"
